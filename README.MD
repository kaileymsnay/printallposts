# Print All Posts

Allows users, if they have the print topic permission for the forum the topic is located, to be able to print view all posts in a topic.

## Installation

1. Copy the extension to: `/ext/phpbbmodders/printallposts`
2. In the ACP, go to: **Customise → Manage extensions**
3. Enable the **Print All Posts** extension
